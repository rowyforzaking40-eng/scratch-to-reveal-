A LITTLE BIRTHDAY ADVENTURE — WEBSITE FILES

Files:
- index.html: the scratch-to-reveal birthday page
- north-wales-property.jpg: your supplied North Wales property photo

Quick preview: keep both files together and open index.html in a browser. For the best mobile experience, host it online.

Publish free with GitHub Pages:
1. Create a new public GitHub repository, e.g. birthday-roadtrip.
2. Upload index.html and north-wales-property.jpg to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Open the Pages URL once it appears and test the scratch reveal on your phone.

The North Wales reveal intentionally doesn't include an exact address or dates. Edit the wording in index.html if you want to add these. Manchester/York/Edinburgh are ideas only; nothing is booked. Destination photos use remote Unsplash URLs and need internet access.
